|-------------|-------------|
| Event RSVP campaigns ($0.67/RSVP) | Cold lead gen for event space ($64/lead) |
| Viral video reach ($0.06/thruplay) | 5 creative variations with no clear winner |
| Community/Oswego-pride angle | Generic "book our space" messaging |
| Low-friction CTA (Interested/RSVP) | High-friction lead forms to cold audiences |

## Workflow: How to Use This System

1. **Monthly review** — Pull 30-day campaign data and compare to targets in each campaign file
2. **New event** — Copy the template from `02_event_template.md`, fill in the event details, launch 14 days before
3. **Retargeting** — `01_retargeting_event_space.md` runs always-on; refresh creative every 3–4 weeks
4. **Awareness** — `03_awareness_always_on.md` rotates content weekly; feed it OCH's best organic posts
