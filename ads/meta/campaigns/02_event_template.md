# Campaign Template: OCH Event Promotion

## Why This Template
The "Sip & Shop For Her" event campaign produced 114 RSVPs at $0.67 each — the most efficient result in the account. This template codifies that structure so every future OCH event can replicate it without starting from scratch.

---

## Campaign Settings

| Field | Value |
|-------|-------|
| Objective | Event Responses |
| Budget | $5–$10/day (scale based on event size) |
| Duration | Start 14 days before event, end day before |
| Buying Type | Auction |
| Bid Strategy | Lowest cost |

---

## Ad Set Settings

| Field | Value |
|-------|-------|
| Ad Set Name | Event: [EVENT NAME] \| Cold \| 25mi |
| Optimization Goal | Event Responses |
| Audience | Broad (no detailed targeting) — Meta's algorithm finds event-goers |
| Locations | Oswego, NY + 25-mile radius |
| Age | 25–60 |
| Gender | Adjust per event type (see notes) |
| Placement | Facebook Feed, Facebook Events tab, Instagram Feed, Reels |

**Gender targeting notes:**
- Ladies' nights, shopping events, wine events → Women 25–60
- Trivia, sports events, general → All genders
- Father's Day, BBQ-focused → Men 30–65

---

## Ad Creative Formula

All event ads follow this structure based on the Sip & Shop winner:

### Primary Text Formula
```
[Hook — call out the audience or occasion]

[What's happening — 2–3 lines, specific details: date, time, what to expect]

[The OCH difference — one line on why this isn't just another event]

[CTA — simple, low-friction]
```

### Headline Formula
```
[Action verb] + [Event Name] @ OCH Oswego
```

## Success Metrics

| Metric | Target |
|--------|--------|
| Cost per RSVP | < $2.00 |
| CTR | > 4% |
| Reach | 5,000–10,000 per event |
| Frequency | 2.0–3.0 (stop if > 4.0) |

## Checklist Before Launching Any Event Campaign
- [ ] Facebook Event created and published on OCH page
- [ ] Event has cover photo (minimum 1200x628px)
- [ ] Event description includes date, time, address, and what to expect
- [ ] Ad links to the Facebook Event (not a website)
- [ ] Campaign ends the day before the event
- [ ] Budget set to at least $5/day for 14 days ($70 minimum per event)
